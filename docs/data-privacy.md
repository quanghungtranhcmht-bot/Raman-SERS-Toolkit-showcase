# Data privacy

This repository is a **public showcase** for Raman-SERS Toolkit.

## What is included
- **Synthetic/anonymized** example CSV spectra located in `examples/sample_data/`
- Example outputs (Excel exports) in `examples/example_outputs/`
- Screenshots and demo media in `assets/`

## What is NOT included
- Any sensitive raw experimental datasets
- Any sample identifiers tied to real projects, people, locations, or timestamps
- Any proprietary instrument or lab metadata

## Notes
- Filenames in the demo dataset are intentionally generic.
- If you need a demo build or want to evaluate the full tool on your data, I can share
  the executable and/or source access **upon request**.
